# カーシュ・カーシュ（cache-cache）

カーシュ・カーシュ（キャッシュとかくれんぼ）。
リソースがどこから届いたかを詳しく、やさしい言葉で表示する Chrome 拡張（Manifest V3）。
Cache Cache（カーシュ・カーシュ）はフランス語で「かくれんぼ」。
「なぜか更新されない」「なぜか遅い」というキャッシュ由来の思い込み・言い訳を、誰の画面でも同じ絵で確認できる共通語にする。

## できること

- **出どころ判定**：ブラウザキャッシュ／ネットワークキャッシュ（CDN）／サーバー（用意していた控え・作りたて・内訳不明）
- **出どころアイコン**：Google Fonts Icons に合わせた `computer` / `cloud` / `host` / `help` をローカルSVGで表示
- **鮮度3モード**：カウントダウン／作成日／非公開（経過のみ）／毎回更新の設定
- **速さ**：実測 TTFB（表示までの速さ）、Fastly MISS 時はサーバー生成時間の目安（X-Timer VE）
- **3層UI**：L1 要点（専門語なし）＋L2 詳細（用語補足つき）＋L3 生ヘッダーを表示
- **再読み込み確認**：通常再読み込み／キャッシュ無視の結果を確認
- **履歴クリア**：この拡張内の履歴を消して再読み込み
- **直近履歴**：同じURLの現在・前回・前々回をタブで切り替え
- **同一サイトCSS**：見た目に効く内部CSSだけ、どこから届いたかを小さく表示
- **共有**：同じURLの生レスポンスヘッダーをまとめてコピー
- **対応CDN**：Fastly（エッジ/シールド・POP都市・X-Timer・Fastly-Debug任意）／Cloudflare／CloudFront／Akamai／RFC 9211 標準 Cache-Status
- **正直さ**：判定できない時は断定せず「特定できませんでした／内訳は不明」と表示
- **安心設計**：`Cookie` や `Authorization` などを含み得る送信ヘッダーは収集しない

## インストール（開発版・unpacked）

1. このリポジトリを取得（`git clone` または ZIP ダウンロード）。
2. Chrome の `chrome://extensions` を開き「デベロッパーモード」を ON。
3. 「パッケージ化されていない拡張機能を読み込む」で本フォルダを選択。
4. ツールバーのカーシュ・カーシュ アイコンをクリック → 右にパネルが開く。
5. パネルの「このサイトだけ許可」を押す（必要なら「すべてのサイトで使う」も選べる）→ ページを再読み込み。

任意のHTTP(S)サイトで確認できます。FastlyなどCDN配下のページでは、ネットワークキャッシュ、返ってきた拠点、鮮度、表示の速さが表示されます。

## 構成

```
manifest.json          MV3 マニフェスト（background type:module・optional host 権限）
service-worker.js      取得層：main_frame / 同一オリジンCSSの webRequest 観測 → 保存・バッジ・perf.js 動的登録
content/perf.js        Navigation Timing（TTFB・メモリキャッシュ補完）を SW へ送信
lib/                   判定エンジン（純関数。拡張本体と Node テストで共有）
  headers / cdn / fastly / cloudflare / cloudfront / akamai / cache-status
  server / freshness / classify / present / pop / format / record
sidepanel/             3層UI（html / css / js）。判定エンジンを import して描画
  header-descriptions.json  レスポンスヘッダー解説（標準・CDN各社などの分類つき）
test/                  ユニットテスト（node --test）。代表的なFastly/CDN応答をフィクスチャ化
tools/make-icons.mjs   アイコン(16/48/128 PNG)を依存なしで生成
```

## プライバシー

- **外部送信なし**：閲覧内容を外部に送信しない。拡張自身はネットワーク通信をせず、解析・広告・トラッキングを一切含まない。
- **端末内のみ・一時保存**：読み取る主ドキュメントのレスポンスヘッダー、表示速度（TTFB）、応答ステータス、サーバーIP、同一サイト内CSSのパスとキャッシュ要約は、ブラウザの `storage.session`（タブを閉じると消える一時領域）にのみ保存する。ディスクへ永続保存せず、端末の外には出ない。
- **収集しないもの**：個人情報、ログイン情報、ページ本文・フォーム内容、閲覧履歴、位置情報は収集しない。`Cookie` や `Authorization` を含み得る**送信ヘッダーも収集しない**。第三者CSSは対象外。
- **第三者提供なし**：データは誰とも共有せず、販売もしない。
- **削除**：タブを閉じればそのタブのデータは消え、ブラウザを閉じれば全て消える。拡張を削除すれば残らない。

## 既知の限界

- メモリキャッシュは webRequest が発火しないことがあり Performance API で補うが、稀に両方取りこぼす → 「特定できませんでした」。
- サーバー側キャッシュと「作りたて」は、サーバーが手がかりを出さなければ見分け不能 → 「内訳は不明」。
- `Fastly-Debug` 注入は多くの本番サイトで無効化されており best-effort。
- SPA のページ内遷移では主ドキュメントの再取得が起きず表示が切り替わらないことがある。
- CSS表示は主HTMLと同一オリジンの `stylesheet` のみに限定する。外部CDN・広告・解析などの第三者CSSは表示しない。
